# 词语连连看 (Lianliankan)

A daily Chinese word-connections puzzle, NYT Connections-style: pick 4 words
out of 16 that share a hidden theme, across 4 categories of increasing
difficulty.

- `index.html` — always shows the current day's puzzle
- `archive.html` — links to every past puzzle
- `puzzles/YYYY-MM-DD.html` — one dated page per day, generated by `generate.py`
- `assets/game.{css,js}` — shared game engine, used by every puzzle page
- `generate.py puzzle.json` — renders a puzzle JSON into a dated page + refreshes `index.html`/`archive.html`

Puzzles are curated daily from current Chinese-language news
(people.com.cn, news.cn, cctv.com), steering toward lighter cultural/science/
sports material over heavy political content.

No backend, no accounts, no stored player data — just a static site.
